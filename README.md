# java-calculator-precourse

## 문자열 덧셈 계산기 구현 기능 목록

### 입력 기능 구현
[x] 구분자와 양수로 구분된 문자열을 입력받는다.

### 예외 발생 기능 구현
[x] 숫자 이외의 값을 입력하는 경우 예외가 발생한다.
[] 구분자 없이 숫자만 입력하는 경우 예외가 발생한다.
[] 음수를 입력하는 경우 예외가 발생한다.
[] 기본 구분자를 이용시, 쉼표(,) 또는 콜론(:) 이외의 문자를 입력하는 경우 예외가 발생한다.
[] 커스텀 구분자를 이용시, // 와 \n 을 정확히 입력하지 않는 경우 예외가 발생한다.
[] 커스텀 구분자를 이용시, // 와 \n 사이에 구분자가 존재하지 않는 경우 예외가 발생한다.
[] // 와 \n 사이에 입력한 구분자와 문자열에 존재하는 구분자가 다를 경우 예외가 발생한다.

### 구분자 분리 기능 구현
[] 공백을 입력한 경우 0을 반환한다.
[] 기본 구분자를 가진 문자열인 경우
    [] 쉼표(,) 또는 콜론(:)을 기준으로 문자열을 분리한다.
    [] 분리된 문자열들을 숫자로 변환한다.
    [] 변환된 각 숫자들을 리스트에 저장한다.
[] 커스텀 구분자를 가진 문자열인 경우
    [] //와 \n 사이에 존재하는 문자를 추출한다.
    [] 추출된 문자를 구분자로 지정하여 문자열을 분리한다.
    [] 분리된 문자열들을 숫자로 변환한다.
    [] 변환된 각 숫자들을 리스트에 저장한다.

### 각 숫자의 덧셈 기능 구현
[] 저장된 숫자들이 담긴 리스트를 불러온다.
[] 리스트에 담긴 모든 숫자의 합을 구하여 반환한다.

### 출력 기능 구현
[] 모든 숫자를 더한 결과를 반환한다.
